# 向量数据库可配置化改造文档

## 概述

项目支持通过配置文件在 **Milvus**（分布式向量数据库）和 **SimpleVectorStore**（Spring AI 内置内存向量库）之间切换，通过 `application.yml` 中的 `vector.store.type` 配置项控制。

## 配置方式

在 `application.yml` 中设置：

```yaml
vector:
  store:
    type: milvus   # milvus | simple
```

- `milvus`（默认）：使用 Milvus 向量数据库，数据持久化
- `simple`：使用 Spring AI 内置 `SimpleVectorStore`，纯内存存储，适合开发/测试

### 默认 profile

```yaml
vector:
  store:
    type: milvus
```

### 生产 profile（prod）

```yaml
vector:
  store:
    type: milvus
```

## 启动方式

```bash
# 默认（Milvus）
./mvnw spring-boot:run

# 使用 SimpleVectorStore
./mvnw spring-boot:run -Dspring-boot.run.jvmArguments="-Dvector.store.type=simple"
```

## 架构设计

### 条件装配机制

使用 Spring Boot 的 `@ConditionalOnProperty` 实现条件装配，两个 VectorStore 实现互斥：

```
vector.store.type=milvus  →  MilvusConfig / MilvusVectorStoreConfig / MilvusSearchService / MilvusIndexService / MilvusCheckController 激活
                          →  MyAppVectorStoreConfig 禁用

vector.store.type=simple  →  MyAppVectorStoreConfig 激活（自动加载 documents/*.md）
                          →  所有 Milvus 相关 Bean 禁用
```

### Bean 命名

两个配置类的 `@Bean` 方法统一命名为 `vectorStore`，注入点不再需要 `@Qualifier`，通过类型（`VectorStore` 接口）注入即可。

### 涉及的类

| 类 | 角色 |
|---|------|
| `MilvusConfig` | 创建 `MilvusServiceClient` Bean（仅 milvus 模式） |
| `MilvusVectorStoreConfig` | 创建 `MilvusVectorStore` Bean 作为 `vectorStore`（仅 milvus 模式） |
| `MyAppVectorStoreConfig` | 创建 `SimpleVectorStore` Bean 作为 `vectorStore`（仅 simple 模式） |
| `MilvusVectorStore` | 手写 Milvus 适配器，实现 `VectorStore` 接口 |
| `UserDocumentServiceImpl` | 文档管理服务，通过 `VectorStore` 接口操作（两种模式通用） |
| `MilvusSearchService` | Milvus 搜索服务（仅 milvus 模式） |
| `MilvusIndexService` | Milvus 文件索引服务（仅 milvus 模式） |
| `MilvusCheckController` | Milvus 健康检查接口（仅 milvus 模式） |

## MilvusVectorStore 关键实现

### add() - 智能分片

```java
public void add(List<Document> documents) {
    for (Document document : documents) {
        if (document.getMetadata().containsKey("chunkIndex")) {
            // 已分片文档 → 直接嵌入+插入，跳过 chunkService
        } else {
            // 未分片文档 → 正常分片流程
            List<DocumentChunk> chunks = chunkService.chunkDocument(...);
            for (DocumentChunk chunk : chunks) {
                // 嵌入 → 插入
            }
        }
    }
}
```

**设计要点**：通过 `metadata` 中的 `chunkIndex` 字段判断文档是否已经过分片，避免二次分片。`UserDocumentServiceImpl` 上传文档时会先分片再传入，`MyAppDocumentLoader` 启动加载时则传入原始文档由 `add()` 自行分片。

### similaritySearch() - Filter 支持

```java
public List<Document> similaritySearch(SearchRequest request) {
    Filter.Expression filterExpression = request.getFilterExpression();
    String milvusFilter = filterExpression != null ? convertFilterExpression(filterExpression) : null;
    List<SearchResult> results = searchService.searchSimilarDocuments(query, topK, milvusFilter);
    // ...
}
```

**设计要点**：将 Spring AI 的 `Filter.Expression` DSL 转换为 Milvus 标量过滤表达式（如 `metadata["userId"] == 123`），使 `UserDocumentServiceImpl.search()` 的按用户过滤功能正常工作。

### Filter.Expression 转换规则

| Spring AI Expression | Milvus 表达式 |
|-----|------|
| `EQ(key, value)` | `metadata["key"] == value` |
| `AND(expr1, expr2)` | `(expr1 and expr2)` |
| `OR(expr1, expr2)` | `(expr1 or expr2)` |
| `IN(key, [a,b])` | `metadata["key"] in [a, b]` |

## SimpleVectorStore 模式说明

### 启动行为

启动时自动加载 `resources/documents/*.md` 下所有 Markdown 文件到内存向量库。

### 数据持久化

- **MySQL**：文档元数据（文件名、大小、分片数等）正常持久化
- **内存向量库**：向量数据不持久化，应用重启后丢失
- **磁盘文件**：上传的文件仍保存到 `uploads/` 目录

### 功能可用性

| 功能 | 状态 |
|------|:---:|
| AI 对话 RAG | ✅ |
| Manus Agent RAG | ✅ |
| 文档上传（向量化入库） | ✅（仅内存） |
| 文档搜索（向量检索） | ✅ |
| 文档删除 | ✅ |
| 文档列表 | ✅ |
| 文档下载 | ✅ |
| `/milvus/health` | ❌（禁用） |

## 注入点汇总

所有注入 `VectorStore` 的位置统一使用类型注入，无需 `@Qualifier`：

```java
// AiController
@Resource private VectorStore vectorStore;

// MyApp
@Resource private VectorStore vectorStore;

// MyAgent 构造函数
public MyAgent(..., VectorStore vectorStore, ...) { }

// UserDocumentServiceImpl
@Autowired private VectorStore vectorStore;
```
